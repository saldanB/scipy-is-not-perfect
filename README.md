# scipy-is-not-perfect

If you’re doing statistics with Python and realized too late that it wasn’t the best choice, this is not your place: it’s never too late to learn R.

But if you want to keep going with your past bad decisions, here I'd like to add tools and tests that aren’t natively implemented in SciPy.

Iplementations:
- Quade test
- Partial Spearman test
